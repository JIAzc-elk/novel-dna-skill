## 三、增量补充方法

准备好补充章节后，运行以下命令并让模型继续完成增量蒸馏即可（`<SKILL_DIR>` 为 `novel-dna-skill` 所在目录）：

```bash
python "<SKILL_DIR>/scripts/novel_pack.py" add --pack "写作包/<作品名>写作包" --input <补充章节路径>
```
