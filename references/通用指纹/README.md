# 通用指纹（所有写作包共用）

通用指纹是技能自带的写作规范，不来自任何一本书，也不需要蒸馏。无论调用哪个写作包、改写还是按纲要写正文，都要带上它。

| 文件 | 类型 | 什么时候用 | 有没有自动检查 |
| --- | --- | --- | --- |
| [告知词禁忌.md](告知词禁忌.md) | 禁忌 | **每一章都查**：动笔前读一遍，交稿前按它自查 | 有：`check_novel_ai.py` 的 `telling-words` 拦截与 `telling-words-note` 提醒 |
| [转场技法.md](转场技法.md) | 知识包 | **需要时调用**：遇到换时间、换地点、换视角、插入回忆时读 | 没有 |

## 和写作包怎么配合

- **禁忌类**（告知词禁忌）是所有稿子的底线，不随写作包豁免。目标原著自己常用这些词，改写时也照样删改；句长、分段、腔调等其余文风仍服从写作包。
- **知识类**（转场技法）是写作包的补充。原著有固定写法的照原著写；原著没覆盖到的情况再用这里的方法。

## 以后想加新的通用指纹

1. 在本目录新建一个 `.md`，开头写清楚它是“禁忌”（每章必查）还是“知识包”（按需调用）。
2. 在上表登记。
3. 禁忌类如果需要自动检查，在 `scripts/check_novel_ai.py` 里加规则，并在 `tests/test_novel_pack.py` 里补正反例测试。
4. 在 `SKILL.md` 第五节的通用指纹清单里登记。
