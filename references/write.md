# 调用写作包：保剧情深度改写与按纲要创作（write.md）

本文件规定如何调用已蒸馏的“小说写作包”完成**已有正文改写**与**章节纲要转正文**。
核心铁律：**锁死叙述人称（改写跟随原稿，按纲要新写一律第三人称）与原稿剧情事实，拒绝同义词降重与胡乱注水，用目标写作包的真实分镜调度与句段呼吸重写叙述肌理！**

---

## 一、动笔前的三步强制校准

用户指定“使用某某写作包”时，严禁凭空捏造文风，必须先完成以下三步：

### 第一步：定位写作包并读取对应指纹模块
1. 使用 `novel_pack.py find` 或直接在 `写作包/` 目录下查找匹配的 `manifest.json`（核对 `name` 或 `aliases`）。
2. 读取 `PACK.md`、`stats.json` 与 `coverage.json`，明确**该目标作品自己的句法基线**（例如：冷峻短句型均句 ~21 字，还是长复句推演型均句 ~36 字；单句成段率是多少；惯用哪些转折推演连接词）。
3. 根据本次待写/待改文稿的场景类型（算账交易、地位差交锋、生死搏杀、日常过渡、高潮蓄势），读取对应的 `指纹/*.md` 模块，提取**句法配方**与**Step 1~4 场景推进模板**。

### 第二步：精读 3~5 个匹配的原文黄金场景切片
1. 根据 `PACK.md` 的场景路由或 `scenes.jsonl` 的标签（`tags`），挑出 **3~5 个最接近本次场景的原文切片**。
2. 运行 `python "<SKILL_DIR>/scripts/novel_pack.py" --json-out .work/slices.json slice --pack <包路径> --scene S001 S002`（或直接打开 `corpus/Cxxxx.md` 对应行号）精读原文。
3. **校准目标**：体会目标作者的**真实句子呼吸感**——看原著如何切入现场、长复句如何层层推演利害、短句在什么节点独立成段砸下结论、角色台词与心理算计如何驱动手头动作。

### 第三步：读通用指纹（所有写作包都要带）
1. 读 `references/通用指纹/告知词禁忌.md`：五类告知词（程度副词、情绪词、多余身体部位、模糊形容词、口头禅过渡词）在叙述里要换成动作、细节和画面。这条不随写作包豁免。
2. 本章有换时间、换地点、换视角或插入回忆时，读 `references/通用指纹/转场技法.md`，先看原著有没有固定转场习惯，没有再从六种写法里挑。

## 二、核心边界：什么必须锁死？什么必须重构？

改写**不是**“把原稿每个词换成近义词来刷低字面重合率”，更不允许为了换句式而篡改人称或往稿子里塞废话！必须严格执行以下边界：

| 维度 | 🔒 必须 100% 锁死的底线（Hard Lock） | 🛠️ 必须按目标写作包重构的对象（Craft Upgrade） |
| --- | --- | --- |
| **叙述人称与视角** | **叙述人称跟随原稿**：第三人称原稿绝对禁止改成第一人称（“我”）自述（仅对白 `“……”` 或带引号的角色直接独白内可用“我”）；第一人称原稿保留第一人称，不得擅自改成第三人称。保持原稿的核心视角归属 | 消除旁白上帝视角的空洞说教，把背景信息转化为角色眼前的感官观察、处境压力与利害判断 |
| **专名、台词与原意** | 全部人名、地名、功法/系统提示框（`【……】`）、古籍引文、账目/修为数字、各方知情边界与结局走向；**原稿中原本就自然传神的核心对白可直接保留** | 重写平庸流水账式的叙述句、说明文式的生硬台词，按目标写作包的“表里双轨对白”补足潜台词与动作停顿 |
| **段落结构与开篇收尾** | 真实因果时间线与核心戏剧转折 | 破除 AI 招牌的“首段报天气+报主角年龄衣着伤疤简历”开篇、监控摄像头式的琐碎过场动作链，以及章末“写天气/地面发亮”打卡收尾 |
| **情绪与感官描写** | 人物此刻的真实处境压力与情绪变化（惊疑、忌惮、决断、松快） | 铲除高危 AI 腻子词（`指腹/垂眸/睨着/嘴角勾起一抹/平淡无波`）与生理通感比喻（`针扎似的凉意/潮水般的疲惫`），改为干净直白的情绪/动作直写 + 具体利害推演 |
| **篇幅与信息密度** | 原稿的每个剧情事件、因果转折与结局都要以场景写出来，不能压成一句梗概；严禁凭空捏造原稿不存在的支线角色或无关剧情注水。门禁只在两稿相差 200 字以上、且改写稿高于原稿 `1.60` 倍或低于 `0.40` 倍时拦截 | **篇幅不设目标比例**：不推动剧情的废话、重复交代、无阻力过场该删就删，删多少都正常；笔墨集中投在冲突交锋、利益算账与关键动作回合上 |

## 三、模式 A：保剧情深度改写四步法（一次成稿 + 定点微调）

> **执行效率与反作弊铁律**：
> - **严禁在改写/创作前读取 `check_novel_ai.py` 源码或自写脚本凑逗号/凑句长**！严禁为了拉长句子把不同主语的两三句话硬把句号改成逗号粘成一团！
> - **严禁陷入“整篇推倒重写”死循环**！正文只用 `write` 落盘 **1 次**（废话照删，但锁死清单里的剧情节点一个都不能丢）；跑完 `check_novel_ai.py` 后若有个别阻塞项（`blocking`），**只准用 `edit` 工具定点修改报错的那几句**！
> - `warnings` 仅作风格参考，**只要 `STATUS=PASS`（`BLOCKING=0`）必须立即交稿**，严禁为了追求零警告反复修改全文！

### Step 1：梳理场景节拍与锁死清单
通读用户原稿，锁定不可更改的角色专名、数字账目、系统面板/引文、因果顺序与章末悬念落点；识别原稿中拖沓的开篇简历、琐碎过场链条和 AI 套词。

### Step 2：按目标写作包句法基线一次性成稿（人称跟随原稿）
1. **开篇切入**：避开“天气+外貌简历”堆砌，优先用冲突动作、反常细节或人物对话切入现场，外貌与背景随行动自然带出。
2. **句段呼吸服从目标写作包 `stats.json`**（门禁按 `narrative_sentence_chars` 叙述句均值校准）：
   - 若目标写作包属于**长复句推演风**（如均句 ~36 字），大方使用 `若是/纵然/然而` 串联两三层利害推演，再以 4~10 字短句单列成段落槌定性，**切勿切成十几字的碎句电报体**；
   - 若目标写作包属于**冷峻短促算账风**（如均句 ~21 字，单句成段率 >50%），则保持干脆利落的因果短复句与高频单句成段，配合带双引号的角色直接心理独白（如：`林玄心中一沉：“……”`）推进算计。
3. **章末收束**：在核心悬念、新危机揭晓或关键决断处果断停笔，严禁画蛇添足加一段“雨还在下/风还在吹”的景物打卡。
4. **演出来，不要告诉读者**（通用指纹 `告知词禁忌.md`）：叙述里不写“他非常生气”“她心里很难过”“她很漂亮”“然后他走进去”，换成动作、表情、具体特征和数量。场景切换按 `转场技法.md` 处理。

### Step 3：正反改写对比示范

**【待改原稿片段】**：
> 渡口的雨还在下。纪衡赶到当铺时，开船的梆子已经敲过头遍，离开船只剩半个时辰。他走进门，把怀里的布包放在柜台上，里面是十八两银子，有碎银，也有两锭成银。他想赎回姐姐的银簪。韩掌柜看了看他湿透的裤脚，拨了一下算盘，说：“赎簪子，二十两。少一分都不行。”韩掌柜知道他赶船，所以不肯让价，嘴角勾起一抹讥诮的弧度。纪衡心里明白，对方是看准了他急着上船才拿乔。他说：“船不等人。这十八两您先收下，剩下的二两明天我姐姐送来。”韩掌柜不同意，说当铺只认现银，不认人情。纪衡胸口像被重锤砸了一下。他沉默了一会儿，没有再争，他知道越是着急，对方越认定他还能拿出二两。他把十八两银子一锭一锭收回布包，系好。韩掌柜看他要走，有点着急，因为银簪死当以后熔了卖，不如赎银划算。他叫住纪衡，说十九两也行，少一文都不行。可是纪衡只有十八两，还是不够，只好转身离开。临走时，韩掌柜在后面喊，说银簪会再留三天。纪衡没有回头求他，把怀里的布包往深处藏了藏。外头雨还在下，渡口的青石板被雨水冲得发亮。

**❌ 【错误改写示范（触犯第一人称红线 / 腻子词二修 / 保留章末天气打卡）】**：
> 漫天雨幕下，我探手将布包摊在柜上。韩掌柜睨着我，唇角泛起抹嘲弄的弧度：“二十两。”我心口猛地蹿起阵重锤似的钝痛，垂眸将银子拢回包中……我把怀里的银包往深处藏了藏，雨还在下，青石板被雨水洗得发亮。
*(病灶：① 擅自将第三人称改成第一人称“我”，触犯网文死忌；② 滥用 `漫天雨幕/睨着/垂眸/泛起抹…弧度` 与吞字怪句 `蹿起阵重锤似的钝痛`；③ 照搬章末写景打卡。)*

**✅ 【正确改写示范（锁死第三人称与事实 + 博弈推演重构）】**：
> 渡口方向的开船梆子已经敲过头遍，离拔锚只剩半个时辰。
> 纪衡跨进当铺门槛，没有半句寒暄，直接将怀里的布包往高柜上一摊。碎银并着两锭成银，拢共十八两，是用来赎姐姐那支银簪的。
> 柜台后的韩掌柜眼皮都没怎么抬，目光先在纪衡湿透的裤脚和急促呼吸上打了个转，慢条斯理地拨动算盘珠子：“赎簪子，二十两。少一分，柜门不开。”
> 纪衡心中一沉：“这老狐狸认得渡口赶船的靴印，吃准了只剩半个时辰，这才坐地拿乔。”他按住柜沿道：“船不等人。这十八两您先收下，差下的二两，明早家姐亲自送来补齐。”
> 韩掌柜嗤笑一声，手掌按住账册：“当铺只认现银，不认明日的人情。银子不齐，免开尊口。”
> 纪衡站在柜前，没有再争辩半句。越是露出非赎不可的急色，对方就越笃定他能从牙缝里再挤出二两银子。纪衡当即伸出双手，将柜面上那十八两银子一锭接一锭拢回布包，系紧了死结。
> 见他真要收银走人，韩掌柜拨算盘的手顿时停住。死当的银簪拿去熔银转卖，终究不如现成的十九两赎银划算；方才压价太狠，若是真把买主逼上了船，这笔到嘴的溢价反倒要落空。
> “慢着！”韩掌柜脸色微变，终究松了口，“看在你姐弟不易的份上，十九两，少一文都不行。”
> 然而纪衡怀里的布包，满打满算也只有十八两。差这一两，今日这支银簪终究是带不上船了。
> 纪衡抱紧银包，转身便往门外走。
> “喂！再给你留三天，过时不候！”韩掌柜的声音从身后追来。
> 纪衡脚步未停，心中纵然发堵，到底没有回头低声下气地求他一句。

### Step 4：运行 `check_novel_ai.py` 门禁（传入 `--source` 与 `--pack`）
```bash
python "<SKILL_DIR>/scripts/check_novel_ai.py" <改写稿.md> --source <用户原稿.md> --pack <目标写作包路径> --output .work/ai_check.json
```
- 确认 `STATUS=PASS`（`BLOCKING=0`，叙述人称与原稿一致、无高危 AI 腻子词与通感比喻、无整句照搬偷懒）即可直接交付！
- 若输出 `STATUS=ERROR`（例如 `--pack` 路径写错），说明根本没有完成检查：先修正路径再重跑，不得当作通过。
- 若原稿存在剧情矛盾或数字漏洞，在正文后另起 `## 附：原稿剧情与逻辑优化建议` 供作者参考。

## 四、模式 B：章节纲要转正文五步法

1. **审阅纲要与确认关键分歧点**：纲要已定的事件、手段、胜负与章末落点直接锁定；仅在缺失核心动机、核心破局机制或结局走向时给 2~3 个简短方案请作者拍板。
2. **拆解节拍表（Beat Sheet）**：拆分为 3~6 个场景节拍，确保每场戏结束时筹码、信息、伤势或局势发生实质推进。
3. **全程第三人称套用写作包配方下笔**：严格遵循目标写作包 `PACK.md` 的句段呼吸与场景推进模板，严禁第一人称叙事，严禁堆砌通感比喻与章末天气打卡；叙述遵守通用指纹 `告知词禁忌.md`，节拍之间的转场参考 `转场技法.md`。
4. **运行门禁校验**：
   ```bash
   python "<SKILL_DIR>/scripts/check_novel_ai.py" <成稿.md> --pack <目标写作包路径> --output .work/ai_check.json
   ```
   确保 `STATUS=PASS`（`BLOCKING=0`）。
5. **交稿核对**：确认未添加纲要禁止的剧情，干净利落交付正文。
