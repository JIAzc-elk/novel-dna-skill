# 中文网络小说叙事红线与反 AI 味手册（revision.md）

本手册旨在拦截违背网文铁律的低级错误与高危大模型腔，同时**尊重不同作者的句法个性，严禁削足适履**。门禁传入 `--pack` 后按目标写作包的叙述句均值、“着”字密度、分号频率和原文用词校准；用一部 2334 章的真人长篇实测，带该书写作包检查原著章节，通过率约 99%。

---

## 第一关：不可触碰的网文叙事红线

### 1. 叙述人称锁死（`first-person-narration` / `pov-changed` 零容忍）
- **按纲要新写**：叙述正文（引号与系统提示框之外）**必须全程使用第三人称**，出现第一人称“我”叙述即拦截（`first-person-narration`）。
- **改写已有正文（`--source`）**：叙述人称**跟随原稿**。
  - ❌ 第三人称原稿改成“我”叙述，拦截 `first-person-narration`；严禁为了“换句式”把原稿的主角名替换成“我”！
  - ❌ 第一人称原稿（自述体）擅自改成第三人称，拦截 `pov-changed`。
- **合法边界**：第三人称稿里，只有角色开口说话的对白（`“……”`）或带双引号的角色直接心理独白（如：`林玄心中暗凛：“此人刀法极快，我绝不可硬接。”`）内部才允许使用“我”。

### 2. 严禁为“降重”胡乱改名换姓、篡改好台词或注水扩写
- 改写不是查重洗稿！原稿的人名、地名、招式名、系统提示框（`【……】`）、古籍引文以及本身简洁有力的对白必须保留。
- **删废话是改写的本职，篇幅不设目标比例**：网文要求每句话都推动剧情，原稿里的空洞铺垫、重复交代、无阻力过场该删就删。要守住的是剧情节点、专名、数字与结局，靠对照锁死清单核对，不靠字数。
- 门禁只拦两种极端（两稿字数相差 200 字以上时）：
  - `length-inflation`：改写稿高于原稿 `1.60` 倍，通常是凭空编造了原稿没有的路人支线或空洞感慨；
  - `length-synopsis`：改写稿低于原稿 `0.40` 倍，通常是把正文压成了梗概，剧情节点只剩一句带过。
  - 介于 `0.40 ~ 0.60` 倍时只给 `length-shrink` 警告，提醒对照锁死清单复核，不拦截。
- 门禁在 `--source` 模式下只拦截**整句原样照搬引号外长叙述句（≥18 字）而不做文风改写**：照搬句数超过改写稿长叙述句的 35%，或改写稿与原稿完全一致时拦截 `verbatim-narrative-copy`，长叙述句多少句都适用；绝不统计无意义的 3 字/5 字专名重合率。

## 第二关：生理反应、修辞与词汇层——铲除大模型招牌病灶

### 1. 情绪与生理反应必须“直给 + 利害推演”，严禁通感比喻（`embodied-simile`）
- **病灶**：大模型极爱把痛觉/触觉比喻硬塞进情绪词里（如 `心口蹿起阵针扎似的凉意`、`胸口像被冷针扎了一下`、`涌起潮水般的疲惫感`、`心脏像被无形大手攥住`）。
- **正向刀法**：
  - ✅ **用简短的生理反应点明情绪**：`心中一寒`、`后背发凉`、`脸色微沉`、`心中一痛`！
  - ✅ **紧接人物脑子里的利害算计或手头动作**：点明反应后立刻写他看穿了什么风险、手头做了什么应对，绝不在胸口、呼吸、指尖上继续堆砌修辞。
  - ❌ **不写情绪标签**：`他感到很难过`、`她心里很高兴`、`心中十分愤怒` 属于告知写法，按通用指纹 `references/通用指纹/告知词禁忌.md` 改成动作和反应（`telling-words` 会统计并拦截）。

### 1b. 通用指纹：五类告知词（`telling-words`，每章必查）
- 叙述里的程度副词、情绪词、多余身体部位、模糊形容词、口头禅过渡词，规则、改法与阈值见 `references/通用指纹/告知词禁忌.md`。
- 只查叙述，不查引号内对白；所有写作包共用，不随目标原著豁免。超过阈值报 `telling-words` 拦截，没超过的报 `telling-words-note` 提醒。

### 2. 严禁二修吞掉量词“一”（`dropped-numeral`）
- **病灶**：大模型改稿时常把 `升起一股`、`泛起一阵`、`透出一丝` 里的“一”抠掉，写成不通顺的 `蹿起阵`、`泛起股`、`带着股`、`透出丝`。
- **刀法**：老老实实写完整 `升起一股寒意`，或直接写动词 `心里发寒`，严禁吞掉“一”字。
- **不拦**：叠词量词（`泛起层层涟漪`、`升起缕缕炊烟`、`带着阵阵寒意`、`透出丝丝笑意`）和名词（`带着阵法`、`带着丝绸`）是正常中文。

> 通感比喻（`embodied-simile`）同样只抓比喻用法：`针扎似的凉意`、`潮水般的疲惫` 会拦；`这般绝望`、`一般的恐惧`、`万般疲惫` 里的“般”不是比喻，不拦。

### 3. 清除高危 AI 网文腻子词（`llm-slop-vocab`）、高频生理套话（`cliche-body-reaction`）与换称呼油滑腔（`elegant-variation`）
- ❌ **必删高危腻子词**：`指腹`、`垂眸`、`睨着`、`斜叼`、`沉腕`、`指节泛白`、`嘴角勾起一抹`、`唇角勾起`、`喉结上下滚动`、`平淡无波`、`没有半分起伏`、`不见半点波澜`、`淡声道`、`缓声道`、`漫天雨幕/重重雨幕`、`悄然收紧`、`敏锐地捕捉`、`森然警告`、`一丝不易察觉的弧度`、`一股难以名状的异样`。
- ❌ **必删朱雀高危生理/眼神套话（`cliche-body-reaction`）**：`深吸一口气`、`倒吸一口凉气`、`瞳孔骤缩/微缩`、`眼中闪过一丝`、`身体一僵`、`手指抠进掌心`、`指甲嵌进肉里`、`攥紧拳头/剑柄没说话`、`空气仿佛凝固`、`死一般的寂静`、`五味杂陈`。切勿把情绪词换成这批大模型高频套话，一律改为手头物件的具体处置或动作失误。
- ❌ **必删翻案辩论句式（`contrast-inversion-formula`）、对比开场套话（`formulaic-exception-hook`）、空喊狠话（`hollow-vow-cliche`）与预告片升华腔（`omniscient-trailer-hook`）**：叙述正文严禁写 `不是/并非X，而是Y`、`与其说X，不如说Y`、`不仅是/不止是X，更是Y`、`X，不代表不能Y`、`没有A，没有B，凭着/只凭C`；严禁写 `寻常人如何，但主角不同`；严禁写无筹码支撑的文绉绉预告狠话（`往后仙路漫漫…他日自会再相逢`、`今日之辱，他日必百倍奉还`）；严禁章末写 `命运的齿轮开始转动`、`这只是故事的开始`、`他不知道的是`。
- ❌ **必删剧透演技标签与变脸套话（`spoiler-acting-tags`）、冗余语气提示（`redundant-speech-tone`）、路人背景解说台词（`dialogue-info-dump`）、精确数字报菜名（`inventory-number-list`）与套路成语轰炸（`cliche-idiom-stuffing`）**：严禁写 `假意/状似无意/佯装/眼波一转/脸上换作一副…的面孔/敛去…换上…/眼底深处掠过/脑中彻底贯通/心中自然雪亮`；严禁在对白已传递情绪时叠床架屋补写 `轻声开口，声音听不出半分波澜`、`声音带着不容置喙的严肃`；严禁借路人插嘴替作者向读者背诵人物身份高低；严禁同句连列 3 项以上 `名物+精确数字+量词`；严禁堆砌或复读套路四字成语。
- ❌ **控制高频状态副词与局部感官词复读（`status-adverb-overuse` & `body-part-sensory-repetition`）**：严禁把 `缓缓/微微/陡然/忽而/半晌/不由得/不知为何` 当作万金油模板反复刷屏，严禁在同一章内密集复读 `指尖/舌尖/喉间/眉梢` 等局部身体词。
- ❌ **破折号清零、异常符号空格清理与中文引号规范（`dash-abuse` / `abnormal-symbol-spacing` / `ascii-straight-quotes`）**：叙述正文严禁滥用破折号 `——` 做补充解释或戏剧停顿；清除正文中 `# / @ / ¥ / *` 等机器符号堆叠与中文标点前后的非自然空格；对白一律使用中文引号 `“…”` 或 `「…」`，严禁英文半角引号 `""`。
- **按目标作者放行**：带 `--pack` 时，如果目标写作包原文里某个词至少出现 2 次（例如作者本人常写“淡声道”），门禁按原著频率的 2 倍放行，并在 `warnings` 里注明 `slop-vocab-allowed-by-pack`。
- ❌ **必删频繁换称呼代词**：严禁在同一场景里反复用 `这位年轻修士`、`那名清瘦道人`、`这位掌柜` 替换人名（超过 2 处即拦截）；直接写人名或省去主语。

## 第三关：结构与句段呼吸层——动态适配目标写作包 + 破除句法平滑

### 1. 砍除五大 AI 结构与句法打卡癖
1. **开篇“天气 + 主角简历”同时堆砌（`machine-opening-inventory`）**：严禁第一段同时报天气环境与主角年龄、衣衫、伤疤；优先从动作、反常处境或对话切入，外貌延后随动作带出。（天气按 `下雨/大雪/寒风/夜色/天色` 等词组判断，人名里的“雪”“风”“雨”不算。）
2. **监控摄像头式过场家务链（`camera-action-list`）**：如一段内连写 6 个以上“站起、拿起、合上、转身、走到门口、推开、坐下”等无戏剧阻力的机械步骤，直接压缩为半句转场。
3. **章末“写天气/地面发亮”或“线索报菜名盘点”（`bookend-weather-ending` & `clue-recap-list`）**：严禁在最后两段写 `雨还在下/风还在吹/青石板被洗得发亮`，也严禁把前文线索用顿号重新罗列汇总一遍；直接在悬念、新威胁或决断处停笔。
4. **复读机强调（`exclamation-echo-abuse`）与周期性景物节拍器（`periodic-prop-filler`）**：严禁“角色刚说出信息→旁白单起一行复述加感叹号”，严禁每隔几段就重复写一次药炉/炭火/茶水充当机械节拍器。
5. **段首主语复读（`subject-monotony`）与单句成段率动态校准（`choppy-telegraph-prose` / `style-too-merged`）**：
   - 严禁连续 3 段或全章超过 38% 的段落以“他/她/主角名”打头！同一人连续行动必须**承前省略主语**，或用器物、声响、动作起段；
   - **单句成段率严格服从目标写作包（`--pack`）**：若目标写作包本身是高频单句成段的冷硬断奏风（如单句成段率 65%），必须保持该断奏率（低于 38% 报 `style-too-merged` 拦截，绝不可强行焊成长段）；未带包或目标包为中长段风格时，防止无脑切成一句一行电报体。

### 2. 句长与分段服从目标写作包（`--pack` 动态校准）
- 不同网文作者的句法呼吸截然不同（例如冷峻短句派平均句长 `20.9` 字，长复句推演派平均句长 `36.1` 字）。
- 运行 `check_novel_ai.py` 时传入 `--pack <目标写作包路径>`，脚本会读取该包的叙述句句长分布（`narrative_sentence_chars`：去掉引号内对白、换行也算句子结束，草稿用完全相同的算法统计）与单句成段率来设定合理上下限：
  - 既防止把多句流水账用逗号硬焊成 150 字畸形病句（`runon-comma-sentence`），或堆成整页不换行的散文豆腐块（`dense-paragraph-blocks`）；
  - 也会在目标包为长复句风格、而草稿切得过碎时给出 `style-too-choppy` 提示，保护目标作者的原汁原味。
  - `--pack` 路径写错时脚本输出 `STATUS=ERROR` 并以退出码 2 结束，不会悄悄换成默认标准。
- 伴随状态词 `着` 默认上限 `11.5 / 千字`（目标作者自己写得更密时，上限放宽到原著频率的 1.6 倍）；微动作补语（`了一下/看了眼/叹了口气`）控制在 `< 2.8 / 千字`（`停了下来`、`布下了阵法`、`悟了道` 不算）；叙述正文分号默认不超过 3 处（目标作者常用分号时按原著频率放宽）。

## 第四关：终稿门禁命令

成稿交付前运行一次本地扫描器（Windows 环境下务必使用 `--output` 写入 UTF-8 JSON 文件读取，避免终端编码乱码）：

```bash
# 保剧情改写模式（校验人称跟随原稿 + 篇幅比例 + 目标包句法适配 + AI 套话清零 + 防整句照搬）
python "<SKILL_DIR>/scripts/check_novel_ai.py" <改写稿.md> --source <用户原稿.md> --pack <目标写作包路径> --output .work/ai_check.json

# 按纲要创作模式
python "<SKILL_DIR>/scripts/check_novel_ai.py" <新写成稿.md> --pack <目标写作包路径> --output .work/ai_check.json
```

**交付标准**：
- `STATUS=PASS`（即 `BLOCKING=0`）即可交付！
- `STATUS=ERROR` 表示检查没有执行（`--pack` 路径错误或文件读不出），修正后重跑，不得当作通过。
- 若有 `blocking` 项，仅使用 `edit` 工具定点修改报错语句；`warnings` 仅作参考提示，**无需为清零 `warnings` 反复重改全文**。
