# 中文网络小说反 AIGC 与深度去 AI 味手册（revision.md）

本手册基于《蛊真人》193 章（61.1 万字）真实语料基线与 `Sepia`、`human-writing`、`story-deslop` 实证校准，旨在从**生成源头与事后校验**双端消除大模型“模型腔”与二修怪句，同时**严禁误伤正常的汉语直白表达与网文节奏**。

---

## 核心铁律：杜绝两类致命 AI 病灶

1. **第一类病灶（一修增肥病）**：大模型把简单动作糊满低困惑度“网文腻子词”（`指腹、探手、睨着、垂眸、应声碎裂、嘴角勾起一抹弧度`）或照抄待改原稿里的 AI 感官比喻（`像吸饱水的馒头、胸口像被冷针扎了一下、墨香压住熏香、章末摸道具+写天气发亮`）。
2. **第二类病灶（二修伪自然病）**：大模型为了躲避机械词表或错误的句长指标，把正常的 `心中猛地升起一股寒意` 扭曲成连语法都不通的 **`心口猛地蹿起阵针扎似的凉意`**，或把七八句话拿逗号强行粘成百字流水账长句！

**真正的网文高手笔力（如《蛊真人》原著实测）**：
- **生理情绪直给 + 立刻接脑子里的利害算计**（原著直写 `心中忽然升起一股寒意`、`心中一寒`、`面色一沉`，紧接 `“……”` 第一人称心声盘算，从不写 `针扎似的凉意`）；
- **句长干脆利落**（原著 61 万字句长均值 `20.9` 字，标准差 `SD = 11.75`，严禁为刷 SD 造百字逗号长句！）。

## 第一关：生理反应与修辞层——“直给 + 算计”，严禁通感比喻与吞字二修

### 1. 情绪与生理反应必须“直给”，严禁塞入比喻修饰（`embodied-simile` 零容忍）
- **病灶**：大模型极爱把痛觉/触觉比喻塞进温觉或情绪词里（如 `心口蹿起阵针扎似的凉意`、`胸口像被一根冷针扎了一下`、`涌起潮水般的疲惫感`、`心脏像被一只无形大手攥住`）。人类网文作者在紧张瞬间绝不会这样堆叠修辞！
- **正向刀法**：
  - ✅ **直接用最自然的现代汉语**：`心中猛地升起一股寒意`、`心里猛地窜起一股寒意`、`心中一寒`、`后背发凉`、`心中一沉`、`脸色微变`！
  - ✅ **用“具体心声算计”代替生理戏精**：写完一句 `心中猛地升起一股寒意`，下一句直接进带双引号的第一人称心声（`“隔着这么大的雨，这人竟能察觉到书房里的动静？”`），绝不在胸口、呼吸、指尖上继续做文章！

### 2. 严禁为躲检测吞掉量词“一”（`dropped-numeral` 零容忍）
- **病灶**：大模型在改稿时常把 `窜起一股`、`泛起一阵`、`带着一股` 里的“一”字抠掉，写成 `蹿起阵`、`泛起股`、`带着股`、`透出丝`，读起来极其别扭。
- **刀法**：要么老老实实写完整 `升起一股寒意`，要么直接写动词 `心里发寒`，严禁吞掉“一”字！

### 3. 彻底剥离待改原稿自带的“四大 AI 打卡道具”（`source-phrase-retention`）
当用户提供的待改原稿本身含有 AI 生成特征时，以下四类内容属于**必须连根铲除的修辞噪音，绝不属于需要保留的剧情事实**：
1. **开篇气味报菜名与馒头比喻**：如“混着米汤味、草药味、马棚粪气”、“账册像吸饱了水的馒头”、“手腕旧疤像被荆条划过”——删掉比喻和气味清单，直接写账房返潮、陈立核账。
2. **转场家务动作链**：如“合上册子→拿干布盖好→洗笔→理齐笔尖→走到门口→停下通报→推门进去”——全部砍掉，一句话直接切入下一个场景的实质交锋。
3. **文青感官特写**：如“顺着一个方向磨墨直到盖住水底砚纹”、“墨香散开压住了熏香味”、“雨水落到身前三寸像撞上看不见的屋檐”——全部改为客观事实或人物心理判断。
4. **章末“摸道具 + 写天气/地面发亮”首尾呼应打卡**：如“把袖中半块麦饼往里藏了藏。雨还在下，长青庄的青石地被雨水洗得发亮”——**一刀砍掉！** 在人物心底的决断、悬念或对话处直接收尾！

## 第二关：语域与句段呼吸层——消灭“AI 伪古风/伪市井角色扮演腔”（193章实测基线校准）

我们对《蛊真人》193 章（61.1 万字）与大模型改写稿做全量统计对比，发现大模型在写网文时有 **5 个肉眼不易察觉、但朱雀等神经检测器一抓一个准的统计断层**：

| 统计维度 | 《蛊真人》193章真人基线 | 大模型典型改写稿（疑似AI 82%+） | `check_novel_ai.py` 强制门禁阈值 |
| --- | --- | --- | --- |
| **开篇切入方式** | 直接以对话 `“……”`、心声算账或突发动作开场 | 先盘点天气+房间物件+主角年龄坐姿衣着伤疤（直接触发 0.99 红线） | `machine-opening-inventory`：首段严禁同时出现天气环境与年龄/衣着/伤疤简历 |
| **现代白话基础虚词密度**（`但是/因为/虽然/这个/这些/现在/可以/这是/都是/他的/已经/什么`） | **`9.52 / 千字`**（P10 `6.6` ~ P90 `12.9`） | **`0.89 ~ 1.37 / 千字`**（被模型当成“水词”删光，变成高密度压缩伪古风） | `plain-function-starvation`：必须 **`>= 4.5 / 千字`**（目标 `7~11 / 千字`） |
| **伴随状态词 `着` 密度**（`敞着/叼着/盯着/看着/扶着`） | **`3.63 / 千字`**（P90 `6.3`） | **`13.5+ / 千字`**（满篇 `V着` 伴随状语，翻了近 4 倍） | `excess-zhe-posture`：必须 **`<= 9.8 / 千字`**（目标 `< 6.0 / 千字`） |
| **伪北方市井方言词**（`今儿/昨儿/里头/外头/后头/瞅着/瞧着/这会儿/心眼儿`） | **`0 ~ 0.02 / 千字`**（61万字几乎为 0，全用标准现代白话） | **`4.0+ / 千字`**（模型开启“市井小人物滤镜”狂飙儿化音与方言） | `fake-folksy-dialect`：整章必须 **`< 3 处`**（目标 `0 处`） |
| **单句成段率 & 平均句长** | 单句成段率 **`57.4%`**，句长均值 **`20.9 字`** | 单句成段率 **`11.9%`**（全是 3~5 句合成的散文豆腐块），句长偏长 | `dense-paragraph-blocks`：单句成段率 **`>= 22%`**（目标 `35%~55%`），平均句长 `<= 25 字` |
| **与待改原稿 3 字/5 字短语重合率** | 独立创作 | 看着原稿逐句换词（5字重合 `10%`，3字重合高达 `23%`） | `source-phrase-retention`：5字重合 **`<= 6.0%`**，3字重合 **`<= 16.0%`** |

### 4. 严禁“看着原稿逐句同义换词”，必须从《场景裸事实账本》重起炉灶
- 只要看着原稿把“坐久了腿麻，跑快了喘”改成“久坐腿麻，快走两步就喘”，把“毛色鲜亮”改成“毛色油亮”，原稿的 AI 分句序列（QUD）就会原封不动保留下来。
- 必须先将原稿提炼为不超过原稿字数 15% 的 `.work/scene_ledger.md`（只含场景、数字、核心因果），再完全脱离原稿句子，用《蛊真人》的**对话开场 + 引号内心算账 + 平实因果复句（`因为…所以…`、`虽然…但是…`、`实际上…`）+ 高频单句成段**重新写出！

### 5. 清除纯 AI 网文腻子词（`PURE_SLOP_WORDS`）与换称呼腔
- ❌ **必删腻子词**：`指腹`、`探手`、`垂眸`、`睨着`、`斜叼`、`沉腕`、`指节泛白`、`嘴角勾起`、`心头一凛`、`神色一肃`、`眼皮猛地一跳`、`通禀`、`腰悬`、`展袖`、`敛去`、`散逸`、`莅临`、`负手`、`平淡无波`、`没有半分起伏`、`不见半点波澜`、`淡声道/缓声道`、`应声碎裂`、`像极了`、`漫天雨幕/重重雨幕`、`似有所察`、`一股/一丝…的(异样/弧度/滞闷/潮腥)`。
- ❌ **必删换称呼油滑代词**：严禁用 `这位管事`、`高凳上的少年`、`那名清瘦道人` 替换人名；直接写人名（陈立、魏福）或省掉主语。
- ❌ **必删段首过渡路标帽**：严禁在段首写 `这种猫腻算不上新鲜`、`一墙之隔，便是两个天地`、`正思忖间`、`念及此处`、`话答得极顺`、`嘴上应得`。

## 第三关：终稿强制门禁——运行 `check_novel_ai.py`

成稿交付前必须运行本地扫描器（改写模式必须传入 `--source <原稿路径>`）：

```bash
# 保剧情改写模式（同时拦截 AI 套路与原稿短语残留）
python scripts/check_novel_ai.py <改写稿.md> --source <用户原稿.md> --output .work/ai_check.json

# 按纲要创作模式
python scripts/check_novel_ai.py <新写成稿.md> --output .work/ai_check.json
```

必须满足：
1. `STATUS=PASS`（`BLOCKING=0` 且 `WARNINGS=0`）；
2. 改写模式下与原稿 5 字短语重合率 `SRC_OVERLAP <= 0.12`（彻底脱离原稿句子骨架）；
3. 句长标准差 `SENT_SD` 落在自然区间（`10.0 ~ 18.0`），无任何 `embodied-simile`、`dropped-numeral` 或 `bookend-weather-ending` 方可交付！
