# 中文网络小说六层观察与拆解维度（L1–L6）

本文件定义如何从网络小说语料中提取**真正具有辨识度、可复刻手感的写作 DNA**。
在拆解任何小说时，必须拒绝“对白要符合人物身份”、“战斗要有来有回”这类放之四海皆准的空话，直击该作者**独有的句法结构、推演步点与叙事机关**。

---

## L1 表层语言与叙事腔调 DNA

观察作者“怎么造句、怎么分段、用什么姿态讲故事”，结合 `stats.json` 的量化数据与原著精读共同提炼：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **句段呼吸与离散度** | `stats.json` 中的句长均值、标准差（SD）、≤10字短句率、≥40字长句率、单句成段率是多少？短句在什么节点砸下？长复句用来干什么？ | **长短句切换公式**：如“4~8字单句成段定格生死/结论 → 30~60字多重复句推演利弊条件 → 简短动作句收束”。 |
| **叙述视角与冷热度** | 是全知俯瞰、单人限知还是多视角轮切？视角切换时用什么引导句（如“对于乙而言，局势却……”）？旁白是冷酷客观、戏谑吐槽还是热血煽情？ | **视角锚定与切换句式**：明确旁白能知道什么、人物心理用直接引语还是自由间接引语、视角转换的标志性连接句。 |
| **标志性句式与词库** | 作者偏爱哪些逻辑转折词（`不是…而是…`、`然而`、`偏偏`、`殊不知`、`恰恰相反`）？偏爱哪些动作动词、程度副词与四字成语？ | **高频句型公式库（5~10个）+ 标志性动词/成语表**：提取原著高频出现的推演句、摊牌句、转折句骨架。 |
| **概述与现场的压缩比** | 重复的修炼、赶路、试招如何一句话带过？哪个瞬间突然放慢成逐帧特写？ | **变速齿轮法则**：“首次操作详写手法 → 重复过程极简概述 → 出现新变量/异常时陡然放慢”。 |

## L2 人物塑造与对白博弈 DNA（融合麦基《人物》《对白》）

人物不是靠形容词贴标签立住的，而是靠**处境限制、压力选择与言语行为（Speech Acts）**立住的：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **出场锚定与处境反差** | 人物出场先写什么？（正在做的事/手头器物/衣着细节/生理限制）。若为重生者或老手，成人心智与幼小/伤残肉身的限制如何互相对照？ | **人物立象三件套**：外在器物/待遇差（显身份）+ 身体/资源硬限制（显处境）+ 第一反应选择（显心性）。 |
| **言语行为（对白在做事）** | 每一轮对话角色真正在干什么？（试探底线、借规矩施压、给台阶、装糊涂、激将、讨价还价、留后路）。 | **对白博弈步点模板**：如“上位者发难 → 下位者先认错避锋芒 → 抛出对方真正在乎的利益/体面漏洞 → 给出不伤面子的台阶方案”。 |
| **表层说辞 vs 内心保留层** | 人物嘴上说的冠冕堂皇理由，与心里真正的算盘如何并置？对方听懂了哪一层、误判了哪一层？ | **表里双轨交锋写法**：“公开台词（合乎规矩/情分）+ 旁白点破未说出口的算计 + 听者的合理误读或顺坡下驴”。 |
| **身份差与群像分层反应** | 上位者与下位者谁掌握打断权、沉默权与定义权？当突发大事时，围观群像如何按各自利益做出不同反应，而非异口同声当捧哏？ | **权力差对话戒律 + 群像分层震动公式**：按“旁观外行（看热闹/惊惧）→ 同辈竞争者（嫉妒/算计得失）→ 掌权老手（看破门道/权衡派系影响）”分层推进。 |

## L3 利益博弈与势力关系 DNA

网络小说（尤其是智斗、权谋、修真经营类）的爽感核心在于**算得清账、立得住局**：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **筹码量化与算账语法** | 作者如何把抽象的“人情、面子、规矩、修为、风险”折算成可比较的具体账目（元石、银两、损耗、时间窗口、替代成本）？ | **利益核算四步法**：“盘点现有家底/收入 → 扣除刚性损耗与底线 → 对比眼下选项的风险收益比 → 拍板取舍”。 |
| **妥协与威慑并存机制** | 弱者如何拿捏强者软肋？如何做到“既给台阶求和，又亮出鱼死网破的威胁”？ | **刚柔并济博弈模板**：以具体信物或行动 placement（如碎尸放后门而非正门）同时传递“愿息事宁人”与“逼急了掀桌子”两层信号。 |
| **敌对合作与防备反制** | 互不信任的双方因何临时联手？联手时如何通过站位、权限留手、互相试探维持脆弱平衡？退让与认输如何体现更高优先级的目标？ | **同舟共济防备模板** + **战略性弃子/认输法则**（不把每次退让写成憋屈，而写成目标排序下的果断止损）。 |
| **势力与制度的显影方式** | 宗门、家族、朝堂的派系倾轧如何不靠“设定集报菜名”写出来？ | **制度后果显影法**：通过“一件私事若闹大，哪个敌对派系会借机发难”、“一笔抚恤/奖励被层层克扣后剩多少”让势力网自然浮现。 |

## L4 战斗、行动与设定落地 DNA

解决“战斗写成招式名称对轰”和“设定写成枯燥百科说明书”两大网文通病：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **战前态势与目标锚定** | 这场战斗的真正目标是什么？（击杀、突围逃遁、拖延待援、夺宝、逼出隐藏第三人）。目标如何决定主角是硬拼还是卖破绽？ | **战局目标先行法则**：开打前先点明胜负判定条件（如“拖得越久谁真元先枯竭”、“未出手旁观者牵制了多少精力”）。 |
| **能力限制与空间地形咬合** | 招式/能力有什么形态缺陷、距离盲区、冷却间隔或克制关系？地形（山壁、窄桥、泥沼）如何放大这个缺陷？ | **能力克制与破招模板**：“展示招式强悍效果 → 暴露形态/消耗/冷却硬限制 → 利用地形或假动作逼对手进入限制区 → 一击破防”。 |
| **设定与职业的“使用即解释”** | 解石、鉴宝、查账、炼丹、布阵等内行戏怎么写才专业？新境界/新体系何时向读者解释？ | **内行鉴识三步法**：“感官观察反常特征（色/重/纹/味）→ 动手复核验证（搓/剖/试）→ 点明成因并落到估价或处置方案”。 |
| **战后代价与收益转化** | 打赢或拿到宝物后，如何处理暗伤、饲养成本、怀璧其罪风险或销赃难题？ | **收益折算与后患钩子**：让战利品/新能力立刻伴随维护成本或新危机，驱动下一阶段剧情。 |

## L5 用典、寓言与情绪主题 DNA

解决“什么时候引经据典”、“怎么插中篇传说不脱节”、“怎么把情绪推到巅峰”：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **诗词与典故的触发与回场** | 诗词或历史典故在什么心境/景物下出现？谁有资格引用？引完之后如何接回眼前的刀剑或算盘？ | **用典三段扣**：“现场景物/绝境触发 → 引用诗句压缩半生阅历或心志 → 落回眼前具体动作/决断（严禁无病呻吟硬塞诗句）”。 |
| **世界内传说/嵌套寓言（如《人祖传》）** | 现场的何种物品/困境触发了世界内传说？传说内部讲了什么欲望悖论？讲完如何用现场一个动作完成同构映射？ | **嵌套寓言同构模板**：“现场核心物件/困境登场 → 切入世界内寓言（独立成篇的欲望与代价抉择）→ 回到同一现场物件，以极短动作完成破局或主题照应”。 |
| **情绪蓄势与主题显影** | 史诗级高潮（如《方源的坚持》）如何构建？普通日常的悲喜、亏欠、温情又如何克制表达？ | **高潮复沓推进法**：“主人公持续单一动作锚点（如一步步前行）+ 外围群像反应层层升级 + 人生切片闪回 + 群像同题不同心的排比爆发”。 |

## L6 连载节奏、信息差与章末钩子 DNA

网络小说是连载艺术，信息何时给读者、何时藏一手、章末停在哪一秒至关重要：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **章节开篇切入模式** | 章节第一段是直接接上章动作、点明环境反常、还是从一句冲突台词切入？ | **开篇切入三式**：动作紧接式 / 局势定格式 / 具象反常切入式（规避空洞景物铺垫）。 |
| **信息差与“先行动后重读”** | 什么时候让读者和主角同步知道计划？什么时候只写主角一个反常举动（如买下废石、主动撞向杀招），等几章或章末再用既有物证揭底？ | **伏笔与事后重读模板**：“前置埋入合理物证與反常小动作（不解释意图）→ 局势爆发 → 回指前文物证揭晓真实算盘（严禁事后凭空捏造机械降神条件）”。 |
| **章末停点（Cliffhanger / Hook）** | 章节最后三行通常停在什么位置？ | **章末断章四模型**：① 致命一击悬停型；② 底牌/真相掀开一角型；③ 身份/态度骤然反转型；④ 冷峻账目/余韵定格型。 |

## 附：无效提炼 vs 有效提炼对照表（自检标尺）

| 维度 | ❌ 无效的常识废话（严禁写入写作包） | ✅ 有效的网文指纹（必须达到的颗粒度） |
| --- | --- | --- |
| **语言** | “长短句结合，根据情况使用修辞。” | “定格生死或翻转结论时用 4~10 字单句成段（如‘大局已定，今日必死无疑。’）；推演各方利弊时用含‘若是…便会…偏偏…’的 40~70 字多重复句，算清后再接一句短促动作。” |
| **对白** | “人物对白随地位压力和信息变化而调整。” | “下位者面对上位者问责时，先顺着对方定性低头认罚（避开正面顶撞），随即点出‘此事若按常理办会坏了哪条规矩/给哪个对头递刀子’，最后奉上替上位者保全面子的折中账目。” |
| **战斗** | “把能力限制和地形结合起来写战斗。” | “先展示防守招式的强悍（如水罩蛊卸力），紧接着由对手视角点破其形态硬条件（必须保持完整圆球，靠墙或倒地即减半），随后的走位与假动作全部围绕‘逼其贴墙/倒地’展开。” |
