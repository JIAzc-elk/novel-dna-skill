# 中文网络小说六层观察与拆解维度（L1–L6）

本文件定义如何从网络小说语料中提取**真正具有辨识度、可复刻手感的写作 DNA**。
在拆解任何小说时，必须拒绝“对白要符合人物身份”、“战斗要有来有回”这类放之四海皆准的空话，直击该作者**独有的句法结构、推演步点与叙事机关**。

## 六层与九个维度名的对应

L1–L6 是阅读时的观察层次。写 `rules.jsonl` 的 `dimension` 字段和 `coverage.json` 时，**只能填下表右列的九个维度名**（`novel_pack.py validate` 只认这九个名字，`coverage.json` 必须九个齐全）：

| 观察层次 | `dimension` 填写值 |
| --- | --- |
| L1 表层语言与叙事腔调 | `语言与叙述` |
| L2 人物塑造与对白博弈 | `人物与对白` |
| L3 利益博弈与势力关系 | `博弈与关系` |
| L4 战斗、行动与设定落地 | `战斗与行动`（打斗、追逃、行动回合）、`世界与题材`（能力体系、职业内行戏、设定落地） |
| L5 用典、寓言与情绪主题 | `修辞与用典`（诗词俗语、嵌套寓言）、`情绪与主题`（高潮蓄势、情绪直述） |
| L6 连载节奏、信息差与章末钩子 | `场景与节奏`（开篇切入、详略变速）、`信息与连载`（伏笔重读、章末钩子） |

L1 表中的“概述与现场的压缩比”属于节奏问题，规则同样填 `场景与节奏`。

## L1 表层语言与叙事腔调 DNA

观察作者“怎么造句、怎么分段、用什么人称和视角讲故事”，结合 `stats.json` 的量化数据与原著精读共同提炼：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **句段呼吸与离散度** | `stats.json` 中的句长均值、标准差（SD）、≤10字短句率、≥40字长句率、单句成段率是多少？短句在什么节点砸下？长复句用来干什么？ | **长短句切换公式**：如“4~8字单句成段定格生死/结论 → 30~60字多重复句推演利弊条件 → 简短动作句收束”。 |
| **叙述人称、视角与冷热度** | 是单主角限知第三人称、同章多视角第三人称轮切，还是第一人称自述体？（**注：按纲要新写正文一律用第三人称，切勿把“改用第一人称”列为缺口或建议；语料本身是第一人称时如实记录**）。视角切换时用什么引导句？旁白是冷酷算账、洒脱冷嘲还是热血悲壮？ | **视角锚定与切换句式**：明确限知边界、角色直接心理独白（`“……”`）与自由间接心理的配比、视角转换的标志性连接句。 |
| **标志性句式与词库** | 作者偏爱哪些逻辑转折词（`若是…便…`、`纵然…也…`、`然而`、`偏偏`、`殊不知`）？偏爱哪些动作动词、程度副词与四字成语？ | **高频句型公式库（5~10个）+ 标志性动词/成语表**：提取原著高频出现的推演句、摊牌句、转折句骨架。 |
| **概述与现场的压缩比** | 重复的修炼、赶路、试招如何一句话带过？哪个瞬间突然放慢成逐帧特写？ | **变速齿轮法则**：“首次操作详写手法 → 重复过程极简概述 → 出现新变量/异常时陡然放慢”。 |

## L2 人物塑造与对白博弈 DNA

人物不是靠形容词贴标签立住的，而是靠**处境限制、压力选择与言语行为（Speech Acts）**立住的：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **出场锚定与处境反差** | 人物出场先写什么？（正在做的事/手头器物/衣着细节/生理限制）。心智与肉身/地位限制如何互相对照？ | **人物立象三件套**：外在器物/待遇差（显身份）+ 身体/资源硬限制（显处境）+ 第一反应选择（显心性）。 |
| **言语行为（对白在做事）** | 每一轮对话角色真正在干什么？（试探底线、借规矩施压、给台阶、装糊涂、激将、讨价还价、留后路）。 | **对白博弈步点模板**：如“上位者发难 → 下位者先认错避锋芒 → 抛出对方真正在乎的利益/体面漏洞 → 给出不伤面子的台阶方案”。 |
| **表层说辞 vs 内心保留层** | 人物嘴上说的冠冕堂皇理由，与心里真正的算盘如何并置？对方听懂了哪一层、误判了哪一层？ | **表里双轨交锋写法**：“公开台词（合乎规矩/情分）+ 旁白或心理独白点破未说出口的算计 + 听者的合理误读或顺坡下驴”。 |
| **身份差与群像分层反应** | 上位者与下位者谁掌握打断权、沉默权与定义权？当突发大事时，围观群像如何按各自利益做出不同反应，而非异口同声当捧哏？ | **权力差对话戒律 + 群像分层震动公式**：按“旁观外行（看热闹/惊惧）→ 同辈竞争者（嫉妒/算计得失）→ 掌权老手（看破门道/权衡派系影响）”分层推进。 |

## L3 利益博弈与势力关系 DNA

网络小说的爽感与真实感核心在于**算得清账、立得住局**：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **筹码量化与算账语法** | 作者如何把抽象的“人情、面子、规矩、修为、风险”折算成可比较的具体账目（元石、银两、损耗、时间窗口、替代成本）？ | **利益核算四步法**：“盘点现有家底/收入 → 扣除刚性损耗与底线 → 对比眼下选项的风险收益比 → 拍板取舍”。 |
| **妥协与威慑并存机制** | 弱者如何拿捏强者软肋？如何做到“既给台阶求和，又亮出鱼死网破的威胁”？ | **刚柔并济博弈模板**：以具体信物或行动同时传递“愿息事宁人”与“逼急了掀桌子”两层信号。 |
| **敌对合作与防备反制** | 互不信任的双方因何临时联手？联手时如何通过站位、权限留手、互相试探维持脆弱平衡？退让如何写成目标排序下的果断止损？ | **同舟共济防备模板** + **战略性弃子/止损法则**。 |
| **势力与制度的显影方式** | 宗门、家族、朝堂的派系倾轧如何不靠“设定集报菜名”写出来？ | **制度后果显影法**：通过“一件私事若闹大，哪个敌对派系会借机发难”、“违规后具体承受何种代价”让势力网自然浮现。 |

## L4 战斗、行动与设定落地 DNA

解决“战斗写成招式名称对轰”和“设定写成枯燥百科说明书”两大通病：

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **战前态势与目标锚定** | 这场战斗的真正目标是什么？（击杀、突围逃遁、拖延待援、夺宝、逼出隐藏第三人）。目标如何决定出手策略？ | **战局目标先行法则**：开打前先点明胜负判定条件与最大掣肘。 |
| **能力限制与空间地形咬合** | 招式/能力有什么形态缺陷、次数限制、真气抽干代价或克制关系？地形（山壁、窄巷、水下）如何放大这个缺陷？ | **能力克制与破招模板**：“展示招式强悍效果 → 暴露形态/消耗/冷却硬限制 → 利用地形或假动作逼对手进入限制区 → 一击定胜负”。 |
| **设定与职业的“使用即解释”** | 解石、鉴宝、查账、炼丹、布阵等内行戏怎么写才专业？新境界/新体系何时向读者解释？ | **内行鉴识三步法**：“感官观察反常特征（色/重/纹/味）→ 动手复核验证 → 点明成因并落到估价或处置方案”。 |
| **战后代价与收益转化** | 打赢或拿到宝物后，如何处理暗伤、饲养消耗、怀璧其罪风险或销赃难题？ | **收益折算与后患钩子**：让战利品/新能力立刻伴随代价或新危机，驱动下一阶段剧情。 |

## L5 用典、寓言与情绪主题 DNA

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **诗词俗语与典故的触发回场** | 诗词、俗语或典故在什么心境/景物下出现？引完之后如何接回眼前的刀剑或算盘？ | **用典三段扣**：“现场绝境/景物触发 → 引用诗句或俗语压缩阅历心志 → 落回眼前具体动作决断”。 |
| **世界内传说/嵌套寓言** | 现场的何种物品/困境触发了世界内传说？讲完如何用现场一个动作完成同构映射？ | **嵌套寓言同构模板**：“现场核心物件/困境登场 → 切入世界内寓言 → 回到同一现场物件完成破局照应”。 |
| **情绪蓄势与主题显影** | 高潮戏如何蓄势？普通日常的悲喜、亏欠、温情又如何克制表达？ | **高潮复沓推进法** + **情绪直给配动作法则**（直述“心中一痛/眼眶发酸”紧接具体手头动作，拒绝通感比喻堆砌）。 |

## L6 连载节奏、信息差与章末钩子 DNA

| 观察项 | 具体拆解问题 | 要提炼出的可复用配方 |
| --- | --- | --- |
| **章节开篇切入模式** | 章节第一段是直接接上章动作、点明处境反常、还是从一句冲突台词切入？ | **开篇切入三式**：动作紧接式 / 局势定格式 / 冲突对白切入式（规避空洞景物+简历铺垫）。 |
| **信息差与“先行动后重读”** | 何时让读者与主角同步知情？何时只写反常举动，等章末或数章后再回指物证揭底？ | **伏笔与事后重读模板**：“前置埋入合理物证与反常小动作（暂不解释意图）→ 局势爆发 → 回指前文物证揭晓算盘”。 |
| **章末停点（Cliffhanger / Hook）** | 章节最后三行通常停在什么位置？ | **章末断章四模型**：① 致命一击将发未发型；② 底牌/身份掀开一角型；③ 局势态度骤然反转型；④ 冷峻格言/账目定格型。 |

## 附：无效提炼 vs 有效提炼对照表（自检标尺）

| 维度 | ❌ 无效的常识废话（严禁写入写作包） | ✅ 有效的网文指纹（必须达到的颗粒度） |
| --- | --- | --- |
| **语言** | “长短句结合，根据情况使用修辞。” | “推演各方利弊时用含‘若是…纵然…然而…’的 35~70 字长复句把两三层后果串完，算清立刻换行，用 4~10 字第三人称短句独立成段落槌定格。” |
| **对白** | “人物对白随地位压力和信息变化而调整。” | “下位者面对上位者问责时，先顺着对方定性低头认罚（避开正面顶撞），随即点出‘此事若闹大会给哪个对头递刀子’，最后奉上替上位者保全面子的折中账目。” |
| **战斗** | “把能力限制和地形结合起来写战斗。” | “先展示防守招式的强悍，紧接着由对手观察点破其硬限制（如维持圆球护罩不可贴墙、灵器一击抽干真气），随后的走位与假动作全部围绕该限制展开。” |
