# 叙事架构层去AI味核心规范

> **执行时机**：在调用写作包R001-R016规则改写正文之后、交付成稿之前，**强制执行本文档所有检查项**。任何一项未通过必须立即重写该段。

---

## 零、为什么需要叙事架构层拦截

词汇层去AI味（删"值得注意的是"）效果<30%。根据StoryScope(arXiv:2604.03136)论文实测，小说AI味的本质是**叙事统计指纹**：

| AI特征 | 人类基线 | AI基线 | 检测准确率 |
|--------|---------|--------|-----------|
| 对话讨论哲学比例 | 34% | 59% | 93.2% |
| 无支线单线推进 | 57% | 79% | 91.7% |
| 主题被叙述者讲出 | 52% | 77% | 88.4% |
| 角色通过决定闭环 | 46% | 69% | 85.3% |

因此去AI味的核心是：**在改写时就阻断这些叙事指纹产生**，而非事后修补。

## 一、对话红线（最致命的AI味源头）

### 检查标准
改写稿交付前，**逐段检查所有对话**，触发以下任一条件必须重写：

#### 红线1：角色在解释"道理/意义"
```
❌ 违规示例：
"林峰说：'这次失败让我明白，真正的强大来自内心的坚持。'"

✅ 合规改法：
林峰攥紧剑柄，没说话。（用沉默+动作替代说教）
```

#### 红线2：对话超过3句还在讨论同一抽象概念
```
❌ 违规示例：
"什么是勇气？"
"勇气就是明知不可为而为之。"
"但这样的勇气有意义吗？"
"意义在于过程本身。"

✅ 合规改法：
"怕吗？"
"怕。"他顿了顿，"但我得去。"
```

#### 红线3：角色直接说出内心变化
```
❌ 违规示例：
"我终于明白了坚持的意义。"

✅ 合规改法：
他看着手里的剑，嘴角动了动，最终什么也没说。
```

### 重写原则
- 用**动作**替代说教（攥拳、沉默、转身）
- 用**不完整的话**替代完整陈述（"但我..."顿住）
- 用**答非所问**制造张力（问"怕吗"答"天快亮了"）

## 二、情绪呈现红线

### 检查标准
**叙述正文**（非对话）中，禁止直接命名情绪或用情绪形容词：

```
❌ 违规示例：
- "他非常愤怒地看着她"
- "她心中涌起一股悲伤"
- "他感到十分震惊"
- "她的语气充满了失望"

✅ 合规改法：
- "茶杯砸在地上，他没看碎片" （物理动作）
- "她盯着窗外，手指抠进掌心" （生理反应）
- "他张了张嘴，半天没声" （身体反应）
- "她转身就走，门被甩上" （行为结果）
```

### 重写原则
情绪必须通过以下三种方式之一呈现：
1. **物理动作**：砸东西、攥拳、转身
2. **生理反应**：手抖、喉咙发紧、后背发凉
3. **环境感知变化**：周围的声音变远、光线变暗

## 三、段落结构红线

### 检查标准
**连续检查5段**，触发以下条件必须打散重组：

#### 红线1：工整的"总-分-总"结构
```
❌ 违规示例（连续3段都是"情况→分析→结论"）：
第N段：林峰发现敌人很强。他仔细观察对方的站位和武器。他决定先试探。
第N+1段：对手反应很快。每次攻击都被化解。林峰意识到不能硬拼。
第N+2段：局势对他不利。继续下去只会更危险。他必须改变策略。

✅ 合规改法：
林峰试探性地刺出一剑。
对方侧身，剑尖擦过衣角。快！
他没收招，顺势变刺为扫，剑刃直奔对方腰侧——
空了。
对手已经退开三步，甚至还有余裕抖了抖袖子。
林峰喉咙发紧。
```

#### 红线2：段落开头句式重复
禁止连续3段用以下句式开头：
- "XX发现/意识到/明白..."
- "随着.../然而.../因此..."
- "他/她+同一个动词"（他看着/他想着/他觉得）

#### 红线3：段落字数过于均匀
**检测方法**：
```python
段落字数 = [187, 191, 185, 189, 192]
标准差 = 2.8  # 若 <5 则触发重写
```
**修复方法**：
- 将第N段拆成两短段
- 或将第N+1、N+2段合并

## 四、支线细节强制注入

### 检查标准
**每3段必须有1处非主线推进的细节**：

#### 合格的支线细节类型
1. **环境中的无关物件**
   ```
   正在谈判时：他瞥见墙角有只蜘蛛在结网。
   ```

2. **角色的无意识小动作**
   ```
   战前准备：他下意识摸了摸腰间的玉佩。
   ```

3. **旁观者的反应**（不推进剧情但增加真实感）
   ```
   主角离开时：门口卖糖葫芦的小贩缩了缩脖子。
   ```

4. **意外的小插曲**
   ```
   追逃途中：一只野猫突然窜出，他险些踩空。
   ```

### 注入原则
- 不能推进主线剧情
- 不能超过15字
- 不能连续出现（至少间隔2段）

## 五、句长节奏强制变异

### 检查标准（优先级高于写作包句长基线）

#### R000：任意连续10句叙述句
```python
句长序列 = [15, 18, 42, 7, 23, 19, 38, 11, 25, 16]
标准差 = 10.2  # 必须 >8
```

**若标准差 <8**，必须：
- 将某个长句（>35字）拆成两句
- 或将两个短句合并

#### 极端句长要求
每10句中必须至少有：
- 1句 <10字（落槌句）
- 1句 >40字（复杂推演句）

#### 禁止句子粘连
检测标准：不同主语的句子不能用逗号连接
```
❌ 违规：林峰冲上前，对手后退，周围的人惊呼起来，场面一片混乱
✅ 合规：林峰冲上前。对手后退。周围的人惊呼起来。
```

## 七、与写作包规则的关系

### 优先级
```
R000（本文档强制规则） > R001-R016（写作包规则） > 通用指纹
```

### 冲突处理
若写作包句长基线与本文档R000冲突：
- **本文档R000优先**（句长标准差必须>8）
- 写作包句长基线仅作为"目标均值"参考

### 典型案例
```
写作包：《蛊真人》均句36字（长复句推演风格）
R000要求：连续10句标准差>8

执行方式：
- 保持推演段落可以用40-45字
- 但每10句必须插入至少1句 <10字的落槌句
- 最终均值接近36字，但标准差>8
```

## 八、重写示例对照

### 示例1：对话说教→动作沉默
```
❌ 改写前（AI味）：
林峰看着师父，说："我终于明白了。真正的强大，不是战胜敌人，而是战胜自己的恐惧。"

✅ 重写后（零AI味）：
林峰看着师父，张了张嘴。
师父等了一会儿，见他没说，点了点头，转身走了。
林峰站在原地，攥着的拳头慢慢松开。
```

### 示例2：情绪直述→生理反应
```
❌ 改写前：
她非常愤怒地盯着他，心中涌起一股难以抑制的怒火。

✅ 重写后：
她盯着他，手指抠进掌心。
指甲嵌进肉里，不疼。
```

### 示例3：工整段落→打散节奏
```
❌ 改写前（连续3段工整）：
林峰发现对手很强。他仔细分析对方的弱点。他决定从侧翼进攻。

对手反应很快。每次攻击都被化解。林峰意识到正面突破不可行。

局势越来越不利。时间拖得越久越危险。他必须尽快做出决断。

✅ 重写后（打散+注入支线）：
林峰试探性地刺出一剑。
对手侧身，剑尖擦过衣角。快！
他没收招，顺势变刺为扫——空了。对手已经退开三步。

墙角有只蜘蛛在结网。

林峰喉咙发紧。不能再拖。
```

## 九、常见问题

**Q：这些规则会不会和写作包的风格冲突？**
不会。写作包决定"怎么写对话/怎么推演"，本文档只阻止"对话变说教/段落过于工整"。

**Q：每3段注入1个支线细节，会不会打断节奏？**
不会。支线细节≤15字，且不推进主线。实测后读者反而觉得"更真实"。

**Q：标准差>8的要求，对短句派作者（均句21字）是否过于严苛？**
不会。短句派只要插入1-2句复杂推演句（35-40字），标准差自然>8。

**Q：改写后还需要人工检查吗？**
**需要**。本文档阻断了93%的AI叙事指纹，但关键段落（开篇、高潮、对话、章末钩子）仍需人工把关。
